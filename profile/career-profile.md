## 働き方の適性（2026-08-08 ヒアリング済み）

**このセクションは記入済みです。** `job-axis.md` の ④適性軸（重み20）はここを根拠に採点します。

### 消耗するもの（減点材料）

| 順 | 内容 |
|---|---|
| ✅ | **締切・障害対応のプレッシャー**（夜間対応、トラブルの呼び出し、納期の重さ） |
| ✅ | **不特定多数からの問い合わせ対応**（ヘルプデスク、窓口、一次受け） |
| ✅ | **部署間の調整・根回し**（社内政治、合意形成、会議の多さ） |
| — | 定型作業の繰り返し ← **これは選ばれていない。維持管理そのものは苦にならない** |

### 手応えを感じるもの（加点材料）

| 順 | 内容 |
|---|---|
| ✅ | **仕組みを改善して効率が上がったとき**（自動化、業務改善、内製化） |
| ✅ | **人に感謝されたとき** |
| — | 自分で作って動かしたとき ← 選ばれていない |
| — | 難しい問題を解けたとき ← 選ばれていない |

### 働き方の好み

- **一人で深く掘りたい**（チームでの分業より、担当領域に集中したい）
- 新規立ち上げ／既存の安定運用は**半々でよい**（この軸では差をつけない）

### この回答から読み取れること

**1. 「問い合わせ対応で消耗する」と「感謝されると手応え」は矛盾しない。**
広く浅い受け身の一次対応は消耗し、特定の相手に深く関わって解決した結果の感謝は報酬、という区別です。ヘルプデスクは減点、研究支援・専任担当は加点、と扱い分けます。

**2. 「難しい問題を解けたとき」より「仕組みを改善して効率が上がったとき」を選んでいる。**
技術的な難易度そのものが報酬ではなく、**技術が誰かの役に立った実感**が報酬という構造です。高度な技術要件を掲げる求人が必ずしも合うとは限りません。

**3. 定型作業の繰り返しは消耗要素に入っていない。**
維持管理・運用が中心の求人を、それだけを理由に下げる必要はありません。

**4. 消耗要素3つは、いずれも「他人のペースに巻き込まれる」性質を持つ。**
締切・問い合わせ・調整は、どれも自分で主導権を握れない仕事です。「一人で深く掘りたい」という回答と一貫しています。**主導権を持てるかどうか**が適性の実質的な判断軸といえます。
