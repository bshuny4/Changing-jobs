# 探索方針と検索クエリ

日次ルーティンが叩く検索クエリの定義です。**クエリの改善はこのファイルを編集するだけ**で翌日から反映されます（`prompts/daily-job-search.md` は触らなくて構いません）。

---

## 探索の配分

| トラック | 配分 | 中身 |
|---|---|---|
| **大学系** | 5割 | 情報系ポジション優先。**専任事務職員（総合職・配属未定）も対象**に含める |
| **民間系** | 3割 | 社内SE・情報システム。年収の相場観を失わないために継続 |
| **異業種** | 2割 | 適性プロファイルから逆算した職種。特許・知財／データ分析・業務改善 |

> **既に取得済みの民間候補は台帳に残します。** 比較対象として機能するためです。

## 最重要のテクニック：ドメイン限定検索

**`allowed_domains: ["www.r-agent.com"]` を付けると、リクルートエージェントの個別求人URLが直接取得できます。**

| 手法 | 個別求人への到達 |
|---|---|
| 一般的なキーワード検索 | 4日間で1件 |
| 企業名・大学名を指定 | 企業ページ止まりが多い |
| **`r-agent.com` 限定検索** | **1クエリで3件** |

これは民間・大学職員・異業種のいずれでも有効でした。**毎日必ず各トラックで1本ずつ実行してください。**

### r-agent の個別求人URLは2形式ある（重要）

**個別求人と判定すべきURLは以下の2つです。片方だけを見ていると取りこぼします。**

| 形式 | 例 | 備考 |
|---|---|---|
| `/viewjob/{hash}/` | `www.r-agent.com/viewjob/jk2270.../` | 当初から把握していた形式 |
| `/kensaku/kyujin/{日付}-{番号}.html` | `www.r-agent.com/kensaku/kyujin/20250111-057-01-029.html` | **8/9に発見。それ以前は一覧ページと誤判定していた** |

一方、**`/job_search/...` は一覧ページ**なのでスコアを付けないでください。

> **8/9 の実測**: コミュニティネットワークセンターの求人がこの第2形式でした。8/5〜8/8 の4日間、この形式を一覧ページとして扱っていたため、**個別求人を取りこぼしていた可能性があります**。

**注意**: r-agent の個別求人ページは**スニペットに年収を載せない傾向**があります。到達率は上がりますが、年収・雇用形態が不明のまま「判定保留」になりやすい点は変わりません（5日連続で年収判明0件）。

### ワークポートは年収を明示する（2026-08-14 発見）★

**`allowed_domains: ["www.workport.co.jp"]`。個別求人URLは `/details/{id}/{id}/` 形式です。**

r-agent が年収を伏せるのに対し、**ワークポートはスニペットに年収レンジと雇用形態を載せます**。日本ガイシの社内SE求人で「400万〜800万・正社員」を一度に取得できました。

**年収の判明率がこの仕組み最大のボトルネック**であることを踏まえ、r-agent 限定検索と並べて**各トラックで1本ずつ実行してください**。

### 転職EX は社名・雇用形態・年収をタイトルに載せる（2026-09-14 発見・民間系限定）★★

**`allowed_domains: ["tenshoku-ex.jp"]`。個別求人URLは `/job_{数字}` 形式です。**

**この媒体の強みは、掲載タイトルに情報を詰め込むことです。**

```
【三井化学株式会社】【愛知】社内SE(工場DX担当) ※年収600万円以上（正社員）
【株式会社MARUWA】【愛知】社内SE ※フレックスタイム制あり（正社員）
【【愛知】社内SE（インフラ）（正社員）】豊田合成株式会社
```

**社名・勤務地・雇用形態が必ず入り、年収や待遇まで入ることがあります。** これは台帳最大のボトルネック（60件中「4軸すべて判明」は4件のみ）に直接効きます。初日に **#59 三井化学が台帳4件目の「4軸すべて判明」候補**として入りました。

愛知県の掲載数は「社内システム開発・運用 645件」「社内情報システム・MIS 937件」と十分です。

🔴 **必ずタイトルの【掲載停止】【募集終了】を確認してください（2026-09-15 追加）。**

転職EX は**掲載が終わった求人もインデックスに残し、タイトルの末尾にその旨を付けます**。

```
【特許技術者【未経験者枠】（正社員）】トヨタテクニカルディベロップメント … -転職EX【掲載停止】
【エアウィーヴマニュファクチャリング】特許・知財（正社員）… -転職EX【募集終了】
【知的財産担当者 ※名古屋（正社員）】日本ガイシ株式会社 … -転職EX【掲載停止】
```

9/15 の異業種検証では、**個別求人6件のうち5件が掲載停止・募集終了**でした。マーカーが付いているので判別自体は容易ですが、**見落とすと死んだ求人を候補化します**。マーカーのあるURLは候補化せず、除外に回してください。

★ **タイトルに社名がなければ「社名非公開求人」です（2026-09-19 追加）。追っても出ません。**

転職EX は**社名が分かっていれば必ずタイトルに入れます**（`【三井化学株式会社】【愛知】社内SE…`）。**社名が入っていない求人は、媒体側が伏せています。**

```
シミュレーション環境企画/運用管理（正社員）／愛知県の《求人募集38772958》  ← 社名なし＝非公開
```

#61 の社名を2回追って取れず、この構造に気づきました。**検索の投げ方の問題ではないので、回数を重ねても出てきません。** 9/16 の「住所・株主構成から引く」手法も、求人票側にその断片がなければ使えません。

**追う価値のある社名不明候補（#57 のように住所が載っている）と、追っても無駄な候補（#61 のように媒体が伏せている）を事前に見分けられます。** 無駄打ちを避けてください。社名はエージェント経由で聞く以外に手がない、と依頼者に伝えるところまでが役割です。

🔴 **職種カテゴリを「社内SE・情報システム」に絞ってください（2026-09-17 追加）。**

転職EX には職種カテゴリが分かれており、**どれを引くかで返ってくる企業の性質がまるで違います。**

| カテゴリ | 性質 | 使うか |
|---|---|---|
| **社内システム開発・社内システム運用**（愛知645件）／**社内情報システム・MIS**（愛知937件） | **事業会社の社内SE**（9/14 の実測: 三井化学・MARUWA・豊田合成・中部電力ミライズ） | **○ こちらを使う** |
| サーバ設計・構築（LAN・Web系）（205件）／ネットワーク運用・監視・保守（380件） | **SIer・SES が多く混じる**（9/17 の実測: テクバン・富士ソフト） | ✗ never条件に触れやすい |

**クエリに「社内SE」「情報システム」を入れ、「ネットワークエンジニア」「インフラエンジニア」という職種名では引かないでください。**

>
> **✗ 「自社内」キーワードは 9/21 に検証し、効果は限定的でした。** 生きた個別求人3件のうち効いたのは1件だけ（クロノステクノロジー）で、**NTTデータ東海の営業職まで混じりました**。絞り込みの主役は依然として**職種カテゴリ（社内SE・情報システム）**です。**クエリに入れてもよいが効果は期待しないこと。**

### ★ 探索と深掘りで手法を切り替える（2026-09-10 確定・重要）

**社名が分からない段階と分かった段階で、使う手法が逆になります。**

| 段階 | 手法 | 理由 |
|---|---|---|
| **探索**（社名が分からない） | **ドメイン限定検索**（r-agent・ワークポート等） | 個別求人URL形式が既知の媒体に絞ると、一覧ページを避けて到達率が上がる |
| **深掘り**（社名が分かった） | **媒体を限定しない** | 社名という強い手がかりがある以上、媒体を絞る意味がない。**絞ると、その媒体に該当社の求人が無い場合に空振りする** |

**9/5〜9/9 の4日間、深掘りにもドメイン限定を使い続けたため個別求人URLが取れませんでした**（日本特殊陶業・アルペン・デンソーIPパートナーズ・タカサゴHD）。9/10 に同じデンソーIPパートナーズを**媒体無指定**で検索したところ、[個別求人URL](https://www.r-agent.com/viewjob/jk474212d1c13b6a9c/)を一発で取得できました（→ #58）。

> **失敗例**: `allowed_domains:["workport"]` ＋ バッファロー・デンソー知財 → 広沢電機工業（電気設備設計）等の無関係な求人。**ワークポートはIT・エンジニア職に強い媒体で知財職の母数が薄い**ためです（Green が愛知の母数が薄かったのと同じ構造）。

### 2段構え：スニペットで見つけ、社名で取る

**8/8・8/9 と2日連続で決定打になった手法です。**

1. 一般クエリを投げる → スニペットに「〇〇大学でシステムエンジニアの募集がある」等の断片だけ見え、URLは一覧ページ止まり
2. **その社名・大学名で再検索する** → 個別求人URLが取れる

中京大学の情報システム課の求人はこの手順で特定しました。スニペットに具体的な組織名が出たのにURLが一覧ページだった場合は、**必ずその名前で再検索してください。**

> **実際には「到達手段」より「検証手段」として効いています（2026-09-07 追記）。**
> 3日で2回、**タイトルだけ見れば完璧な求人が、社名特定で県外と判明して除外**されました。9/5 の `jk4d8af44433bdc1f8`（インフラ企画・NW/AD/NetApp）は知財最大手グループの大阪・東京勤務、9/7 の JREC-IN `D123061466`「**大学技術職員（情報システム担当）**」は横浜市（岩崎学園系）でした。
> 後者は職種名がこの仕組みの探索目標そのもので、業務内容も現職と完全に重なります。**検証せず台帳に入れていたら、横浜の求人を最優先候補として提示していました。**
> **JREC-IN も r-agent も勤務地をスニペットに載せません。県外混入は構造的に起きます。個別求人を候補化する前に、勤務地が読み取れなければ必ず社名・組織名で再検索してください。**

> **★ 社名が伏せられている求人は、住所・最寄り駅・株主構成から引けます（2026-09-16 追加）。**
