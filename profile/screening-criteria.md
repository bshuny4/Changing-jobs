# 探索方針と検索クエリ

日次ルーティンが叩く検索クエリの定義です。**クエリの改善はこのファイルを編集するだけ**で翌日から反映されます（`prompts/daily-job-search.md` は触らなくて構いません）。

---

## 探索の配分

| トラック | 配分 | 中身 |
|---|---|---|
| **大学系** | 5割 | 情報系ポジション優先。**専任事務職員（総合職・配属未定）も対象**に含める |
| **民間系** | 3割 | 社内SE・情報システム。年収の相場観を失わないために継続 |
| **異業種** | 2割 | 適性プロファイルから逆算した職種。特許・知財／データ分析・業務改善 |

> **既に取得済みの民間候補は台帳に残します。** 比較対象として機能するためです。

## 最重要のテクニック：ドメイン限定検索

**`allowed_domains: ["www.r-agent.com"]` を付けると、リクルートエージェントの個別求人URLが直接取得できます。**

| 手法 | 個別求人への到達 |
|---|---|
| 一般的なキーワード検索 | 4日間で1件 |
| 企業名・大学名を指定 | 企業ページ止まりが多い |
| **`r-agent.com` 限定検索** | **1クエリで3件** |

これは民間・大学職員・異業種のいずれでも有効でした。**毎日必ず各トラックで1本ずつ実行してください。**

### r-agent の個別求人URLは2形式ある（重要）

**個別求人と判定すべきURLは以下の2つです。片方だけを見ていると取りこぼします。**

| 形式 | 例 | 備考 |
|---|---|---|
| `/viewjob/{hash}/` | `www.r-agent.com/viewjob/jk2270.../` | 当初から把握していた形式 |
| `/kensaku/kyujin/{日付}-{番号}.html` | `www.r-agent.com/kensaku/kyujin/20250111-057-01-029.html` | **8/9に発見。それ以前は一覧ページと誤判定していた** |

一方、**`/job_search/...` は一覧ページ**なのでスコアを付けないでください。

> **8/9 の実測**: コミュニティネットワークセンターの求人がこの第2形式でした。8/5〜8/8 の4日間、この形式を一覧ページとして扱っていたため、**個別求人を取りこぼしていた可能性があります**。

**注意**: r-agent の個別求人ページは**スニペットに年収を載せない傾向**があります。到達率は上がりますが、年収・雇用形態が不明のまま「判定保留」になりやすい点は変わりません（5日連続で年収判明0件）。

### ワークポートは年収を明示する（2026-08-14 発見）★

**`allowed_domains: ["www.workport.co.jp"]`。個別求人URLは `/details/{id}/{id}/` 形式です。**

r-agent が年収を伏せるのに対し、**ワークポートはスニペットに年収レンジと雇用形態を載せます**。日本ガイシの社内SE求人で「400万〜800万・正社員」を一度に取得できました。

**年収の判明率がこの仕組み最大のボトルネック**であることを踏まえ、r-agent 限定検索と並べて**各トラックで1本ずつ実行してください**。

**媒体ごとの得意分野**（2026-08-19 時点の実測）

| 媒体 | 強み |
|---|---|
| **ワークポート** | **年収・労働条件の明示が最も安定**。知財の個別求人はパソナより強い（8/18 パソナ0件 → 8/19 ワークポート1件） |
| **パソナキャリア** | 年収＋待遇（転勤なし／リモート／住宅手当）まで載る。民間系に強い |
| **r-agent** | 到達数は多いが**年収を伏せる傾向**。一覧ページ比率も高い |
| **マイナビ転職** | 大学系IT子会社の個別求人が取れた（#27 エヌ・エフ・ユー） |

**未検証**: doda・エン転職にも同様の個別求人URL形式がないか、順次試す価値があります。

### 2段構え：スニペットで見つけ、社名で取る

**8/8・8/9 と2日連続で決定打になった手法です。**

1. 一般クエリを投げる → スニペットに「〇〇大学でシステムエンジニアの募集がある」等の断片だけ見え、URLは一覧ページ止まり
2. **その社名・大学名で再検索する** → 個別求人URLが取れる

中京大学の情報システム課の求人はこの手順で特定しました。スニペットに具体的な組織名が出たのにURLが一覧ページだった場合は、**必ずその名前で再検索してください。**

## トラック1：大学系（配分5割）

### 1-A. r-agent 限定検索 ★毎日

```
allowed_domains: ["www.r-agent.com"]
  1. 大学職員 学校法人 事務職員 愛知 名古屋 求人
  2. 大学 情報システム 職員 愛知 求人 情報基盤
```

> このクエリで、5日間スニペットだけ見えてURLを特定できずにいた東海市の情報システム求人を特定できました。

### 1-B. 一般検索 ★毎日

```
1. 私立大学 専任事務職員 募集 愛知 名古屋 経験者採用 情報システム
2. 大学 職員 中途採用 募集 愛知 名古屋 学校法人 専任職員 年収
3. 大学 情報システム課 情報基盤センター 職員 中途採用 募集 愛知 名古屋 専任
```

> **★3 は部署名を直接入れるクエリです（2026-08-19 に有効性を確認）。**
> 大学側が使う正式な部署名（**情報システム課／情報基盤センター／情報メディアセンター/情報処理センター**）をクエリに入れると、配属が明記された求人や大学系IT子会社に当たります。
> 8/18 は「情報システム課」を入れて #26 愛知大学（配属限定）に、8/19 は同クエリのスニペットから **#27 エヌ・エフ・ユー（日本福祉大学系）** に到達しました。**2日連続で決定打**になっています。部署名は上記4つをローテーションしてください。

### 1-C. JREC-IN ★隔日（飽和のため頻度を落とす）

```
allowed_domains: ["jrecin.jst.go.jp"]
  1. 大学 情報センター 職員 求人 募集 愛知 名古屋 情報システム 技術職員
  2. 情報基盤センター 技術職員 事務職員 募集 東海 中部 愛知
```

> **5日連続で飽和しました。** 同じ求人しか返さず、新規はほぼ教員公募です（ある日は新規10件中8件が教員）。ただし名古屋大学の技術職員2件という上位候補の出所でもあるため、隔日で回します。
> **教員公募（准教授・助教・教授・講師）は必ず除外**してください。

### 1-D. 大学の採用ページ ★週1ローテーション

`{大学名} 職員採用 情報システム 情報センター 募集` で検索。1日3〜4校、約5日で一巡。

| 区分 | 大学 |
|---|---|
| 国立 | 名古屋大学、名古屋工業大学、愛知教育大学、豊橋技術科学大学 |
| 公立 | 名古屋市立大学、愛知県立大学 |
| 私立 | 南山、名城、中京、愛知、中部、愛知工業、愛知淑徳、藤田医科、金城学院、椙山女学園、名古屋学院、愛知学院、星城 |

**判明済みの条件**（安定軸の判定に使う）

| 大学 | 条件 |
|---|---|
| 名城大学 | 年間休日134日、定年65歳 |
| 愛知学院大学 | 年間休日129日、夏季休暇（自由10日）、定年62歳（65歳まで再雇用） |

### 1-E. 大学職員求人News（jobnews.jp）★毎日（2026-08-19 新設）

```
allowed_domains: ["www.jobnews.jp"]
  大学職員 求人 愛知 情報システム 事務職員 採用
```

**愛知県49校の自校採用情報を集約しているサイトです。** 大学が自校サイトだけで出し、JREC-INにも転職エージェントにも載せない募集を拾える可能性があります。**JREC-INが7日連続で空振りしている穴を埋める候補**として新設しました。

**未検証**: 8/19 の初回実行では、掲載が契約職員・パートのみ（=must条件の無期雇用を満たさず）で収穫0でした。一覧ページから個別求人への到達性はまだ確認できていません。数日回して成果が出なければ廃止してください。

### ✗ persona-ats.com は大学チャネルとして機能しない（2026-08-19 検証済み・実行不要）

`job.persona-ats.com` のドメイン限定検索を試したところ、**10件中、大学は愛知大学1校のみ**で、残りは BUB・Sun Asterisk・キカガク等の民間企業でした。**PERSONA は大学向けATSではなく汎用ATS**で、愛知大学がたまたま採用していただけです。

> #26 に到達できたのはドメイン限定検索ではなく、**キーワード検索（部署名）から偶然辿り着いた**ためでした。**このドメイン限定検索は実行しないでください。**
> ただし「**大学が自校ATSで直接募集するパターンがある**」という発見自体は有効です。ATSドメインを狙い撃つのではなく、1-B の部署名クエリで拾うのが正解でした。

## トラック3：異業種（配分2割）

適性プロファイルから逆算した仮説は「**技術がわかることが前提で、一人で深く掘れて、締切より正確さが問われる仕事**」です。

| 方向 | 判定 | 状況 |
|---|---|---|
| **特許技術者・知財** | ★有望 | 総合3.31で候補入り。年収470〜650万、残業月20h以内、未経験可の求人あり。愛知は製造業集積で需要が構造的に大きい |
| **データ分析・BI・業務改善** | △条件付き | 報酬パターンに直撃するが、求人の大半がコンサル職で調整業務を伴う。**事業会社内のポジション**なら適性が高い |
| 医療情報システム | ✗不適合 | 故障対応・保守サポート・客先常駐が消耗パターンに該当。**探索しない** |
| テクニカルライター | ✗条件外 | 適性は最高だが年収350〜380万で must条件（450万）を下回る。**探索しない** |

### 3-A. 継続クエリ ★毎日1本（ローテーション）

```
1. 特許技術者 知財 未経験可 中途採用 求人 愛知 名古屋 理系 年収
2. allowed_domains: ["www.r-agent.com"] → 知的財産 特許 愛知 名古屋 求人 未経験
3. allowed_domains: ["www.r-agent.com"] → BIツール データ分析 業務改善 RPA 愛知 事業会社 転勤なし
```

### 3-B. 社名で深掘りすべき先

個別求人URLが取れていない企業。社名で再検索する価値があります。

- **ベルパーク** — BIツール設計開発・運用、業務効率化（RPA(WinActor)、Python）、転勤なし、時短在宅可。**事業会社内のポジションで適性が高い可能性**
- アビームシステムズ — 新技術コンサル（BigData/AI/RPA/IoT）、未経験歓迎、在宅OK、転勤なし
- デジタルフォルン — データ分析コンサル、業務効率化/自動化の経験者歓迎
- 株式会社三五（みよし市） — 知財・技術法務、未経験可

## 実行時のルール

- 各トラックは独立なので **WebSearch を並列実行**してください
- 同一求人が複数トラックでヒットしたら**URLで名寄せ**して1件に統合
- **一覧ページにはスコアを付けない**。「参考」に「一覧ページ。個別求人は要確認」と明記
  - ただしスニペットに具体情報（年収レンジ・勤務地・業務内容）があり**スコアリングに足りるなら採点してよい**。その場合はURLが企業ページ・一覧ページであることを明記する
  - 個別URLが特定できない求人は**URLを載せず**、探索ログの所感に「〇〇で要検索」と書く
- 検索結果0件のトラックがあっても異常ではありません。記録するだけで構いません
